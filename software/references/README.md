# Severance screen references

The default follows the simple blue monospace layout the user preferred on
27 September. The optional MDR layout is adapted from the terminal interface
used in *Severance*, with real Trello task selection and ticket printing.

Inspected actual scene excerpts from the MDR department:
[HUDS+GUIS — Severance UI Design](https://www.hudsandguis.com/home/2022/severance).
`completion.gif` and `rolodex.gif` are reference clips from that page;
`*-frames.jpg` files are selected frames for visual inspection. These are not
shipped to or displayed by the application.

Observed screen elements: a very dark blue field with cyan lettering, a compact
file header and Lumon globe on the right, horizontal and double-line rules,
small percentage readouts, and numbered rectangular bins along the bottom.
The lettering is proportional rather than a generic command-line mono font.
The production's exact typeface is not established here; Liberation Sans is a
single-family approximation, not a claimed match.

The optional task UI adapts the header and bin structure. Its three bins are actual
New Task, Complete and Skip controls. Its progress indicator is the elapsed
focus-session time, labelled “Elapsed,” rather than an invented task completion
percentage. Both layouts include a small decorative number field during focus sessions;
they do not load the numeric game, fake coordinates or scene clips.

Background production context:
[Jeremy Hindle interview, The Credits](https://www.motionpictures.org/2022/06/severance-production-designer-jeremy-hindle/).
