# Rear-loading integral-front printer bay

Active mechanical study: cad/rear_loading_v21.py. Supersedes v20 front-module studies.

The user confirmed front-output printing and supplied 131 W × 175 D × 120 H mm desktop dimensions. Rotated body is 131 W × 120 D × 175 H mm. Native keyholes: 61mm centres, larger-hole centre line 132mm from original rear/cable edge; retained as reference but not used for mounting.

Mounting: a tray supports the body; two side guides leave 1mm nominal clearance each side. Integral front perimeter overlaps the body by 2mm nominally. Two removable rear bars retain it with 0.5mm nominal rear clearance. Optional thin removable shims can take up play; avoid an interference fit. The bars screw into the shell using tested 4.2mm M3 insert bores. Verify the printed pads land on solid printer casing and do not obstruct its cables.

Service: disconnect cables, remove the rear cover (4 screws), remove both retaining bars (4 screws), slide the intact printer rearward, replace paper, reinstall. Top cover can remain fitted according to the conservative rectangular-body sweep check. Native corner radii need not match the cradle. The existing printer body stays assembled.

Fasteners for these parts: four M3×12 screws for 6mm retaining bars (6mm nominal engagement); four M3×14 screws for rear cover including spacers (4.5mm nominal engagement); two M3×8 for 4mm top (4mm nominal engagement). These lengths are present in the user's kits; verify no bottoming during assembly. Main spine fasteners remain inherited and are not included in this subtotal.

Six single-solid, watertight parts; pairwise and reference-envelope checks must pass checks.json. Rear-removal sweep excludes only the removed bars and rear cover and retains the top. Shell exported front-face down to avoid a broad opening roof bridge; right rear rail has a 45-degree transition. Slicing and actual support review are still required. All these structural parts are grey/A2, on separate plates if needed. No print was sent.

Mechanical-study limits: box reference is not an exact printer model; native lid/buttons/cutter and cable paths remain to be physically checked. Housing design height is 201mm, so the overall display/printer silhouette and cosmetic radii/logo still need integration. Do not present this square mechanical study as the finished Lumon design.
